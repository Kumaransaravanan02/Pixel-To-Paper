# Pixel-To-Paper

An AI-powered application that converts digital documents into handwritten-style PDFs while preserving layout and formatting.

## Features

- PDF to Handwritten PDF
- Image to Handwritten PDF
- Custom handwriting fonts
- Layout preservation
- Streamlit interface

## Technologies

- Python
- Streamlit
- PyMuPDF
- Pillow
- OpenCV
- FontTools

## Installation

pip install -r requirements.txt

streamlit run app.py
